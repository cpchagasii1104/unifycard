# System Declaration — UnifiCard

## O que é o sistema
- Uma infraestrutura de participação humana
- Baseada em trabalho, habilidades e serviços
- Mediando mercado, governo e sociedade

## O que o sistema NÃO é
- Não é assistencialismo passivo
- Não é renda sem vínculo
- Não é plataforma ideológica

## Linguagem comum
- Árvore canônica de categorias
- Contextos semânticos claros
- SSOT de leitura

## Princípio de acesso
- Participação gera oportunidade
- Não existe benefício sem atividade

## Governança
- Core congelado
- Extensão por contextos
- Soberania por tenant
- Testes e observabilidade ativos

## Escala
- Funciona para indivíduo
- Funciona para empresa
- Funciona para governo
- Sem refatoração estrutural

## Declaração final
- O sistema foi projetado para durar décadas
- Não depende de ideologia
- Depende apenas de participação humana real
