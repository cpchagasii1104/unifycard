# Category Tree — Canonical Integration Map

## Objetivo
- Mostrar como a árvore canônica se conecta aos módulos
- Sem duplicação, sem acoplamento indevido

## Princípio Central
- A árvore NÃO pertence a nenhum módulo
- Módulos CONSUMEM a árvore
- A árvore nunca depende de módulos

## Conexões por Módulo

### Perfil
- Usa categorias para:
  - habilidades
  - interesses
  - aprendizado
- Contexts: person, interest, learning

### Empresas
- Usa categorias para:
  - atividade econômica
  - serviços oferecidos
- Contexts: company, professional

### Marketplace / Shop
- Usa categorias para:
  - classificar ofertas
- Contexts: professional, economy

### Serviços
- Usa categorias para:
  - matching de prestadores
- Contexts: professional, person

### Eventos
- Usa categorias para:
  - tipo de evento
  - público-alvo
- Contexts: interest, professional, government

### Projetos
- Usa categorias para:
  - áreas de atuação
- Contexts: professional, infrastructure

### Comunidades
- Usa categorias para:
  - afinidades
- Contexts: interest, person

### Governo
- Usa categorias para:
  - políticas públicas
  - infraestrutura
- Contexts: government, infrastructure

## O que é PROIBIDO
- Módulo criar categorias próprias
- Módulo alterar árvore
- Módulo criar hierarquia paralela

## Impacto
- Linguagem comum entre módulos
- Matching cross-sistema
- Escala sem refatoração
