# GATE 2 — CHECKS

Checks mínimos enquanto o Gate 2 estiver ativo:

- Revisão manual obrigatória em qualquer mudança que:
  - toque dinheiro
  - crie/edite repositórios financeiros
- Proibido introduzir novos writers legacy
- Proibido usar leitura legacy para decisão

Dependências:
- `GATES.md` (define Gate 2)
- `GATE_2_BLOCKERS.md` (bloqueios estruturais ativos)
- `FALSIFICATION_LOG.md` (registro de violações detectadas nos checks)

Checks automatizados (opcional/futuro):
- grep por INSERT/UPDATE/DELETE em estruturas proibidas
- lint/CI para bloquear padrões listados em PROHIBITED_STRUCTURES.md
