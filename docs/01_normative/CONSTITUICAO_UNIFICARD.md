# SEÇÃO I — CONSTITUIÇÃO (IMUTÁVEL)
# ═══════════════════════════════════════════════════════════════════════════

> Esta seção é **IMUTÁVEL**. Qualquer alteração requer emenda formal.

## PREÂMBULO

O UnifiCard é um sistema operacional social unificado.
- Ele não promete justiça perfeita.
- Ele não corrige humanos.
- Ele não decide por pessoas.
- Seu objetivo é resistir à injustiça em escala sem recorrer a coerção técnica.

---

## ARTIGO I — Soberania do Ator

1. Todo ator é soberano.
2. Nenhum ator controla outro ator.
3. Empresas coordenam; pessoas decidem.
4. Não existem contas-deus, chaves-mestras ou bypass administrativos.

**Razão:** Controle técnico inevitavelmente vira abuso humano.

---

## ARTIGO II — Agenda como Verdade Única

1. A agenda (Unified Availability) é a única fonte de verdade sobre disponibilidade.
2. Conflito nunca gera ação automática.
3. Conflito gera fato.
4. Fato gera alerta.
5. Alerta vai para o humano.

**Proibição:** Bloquear, resolver ou otimizar conflitos automaticamente.

---

## ARTIGO III — Feed como Orquestrador Visual

1. O feed não executa ações de domínio.
2. O feed não decide comportamentos.
3. Plugins apenas declaram DTOs e ações possíveis.
4. A ausência de um plugin não autoriza inferência.

**Razão:** Visibilidade não pode virar poder executivo.

---

## ARTIGO IV — Inbox como Read-Model

1. Inbox organiza fatos.
2. Inbox não decide.
3. Inbox não prioriza.
4. Inbox não executa.
5. Ordenação é apenas temporal.

**Proibição:** Score, ranking, urgência algorítmica.

---

## ARTIGO V — Economia com Consentimento Explícito

Toda movimentação financeira exige:
1. Ator identificado
2. Evento canônico
3. Consentimento explícito
4. Não existe ajuste administrativo
5. Não existe modo emergencial
6. Reversão só pelo ator que executou

**Razão:** Exceção financeira destrói confiança sistêmica.

---

## ARTIGO VI — Ausência de Juiz Automático

1. O sistema não arbitra disputas sociais.
2. O sistema não resolve conflitos humanos.
3. O sistema não determina vencedores.

**Razão:** Juiz invisível é tirania silenciosa.

---

## ARTIGO VII — Proibição de Crescimento do Core

O core não recebe features. O core recebe apenas:
1. Contratos
2. Blindagens
3. Correções de segurança
4. Toda inteligência é plugin ou módulo externo.

**Razão:** Core inchado vira legado irrecuperável.

---

## ARTIGO VIII — Meta-Observabilidade Social

1. O sistema observa padrões, não indivíduos.
2. Observações são: agregadas, retardadas no tempo, não acionáveis automaticamente.
3. O objetivo é expor concentração, não corrigi-la.

**Proibição:** Vigilância individual, ranking humano, score social.

---

## ARTIGO IX — Anti-Automação Ética

1. Consentimento não pode virar reflexo.
2. O sistema pode introduzir fricção cognitiva não manipulativa.
3. Fricção nunca esconde opção nem induz escolha.

**Razão:** Consentimento sem atenção é ficção jurídica.

---

## ARTIGO X — Direito à Opacidade Pessoal

1. Nenhum indivíduo pode ser inferido a partir de dados agregados.
2. Limiares impedem identificação reversa.
3. Poder individual não é provável via sistema.

**Razão:** Transparência total gera vigilância social.

---

## ARTIGO XI — Governança e Emendas

1. Mudanças constitucionais exigem emenda explícita.
2. Emendas são públicas.
3. Emendas são justificadas.
4. Emendas nunca são silenciosas.

**Razão:** Evolução sem memória é traição.

---

## ARTIGO XII — O que o Sistema NÃO Fará

- ❌ Não otimizará comportamento humano.
- ❌ Não corrigirá desigualdade automaticamente.
- ❌ Não ranqueará pessoas.
- ❌ Não esconderá poder atrás de UX.
- ❌ Não substituirá decisão humana.

---

## DISPOSIÇÃO GERAL — INSTRUMENTAÇÃO PARA AGENTES (SEM NOVA NORMA DE PRODUTO)

A operação de agentes automatizados sobre este repositório **não cria exceção** aos artigos I–XII. Para **ordem obrigatória de leitura da normativa**, **gate antes de qualquer alteração estrutural** e **proibições operacionais explícitas para IAs**, remete-se a `docs/01_normative/00_AGENT_PROTOCOL.md` (secções 2.3.1 a 2.3.7). Em caso de conflito interpretativo entre esse protocolo e este documento, **prevalecem** os artigos constitucionais acima.

---

> Se este documento parecer excessivamente restritivo, ele está correto.
> Se alguém tentar "melhorar" o sistema violando estes artigos, o problema não é técnico — é constitucional.
