# Observabilidade Constitucional — UnifiCard

Este documento descreve o papel da observabilidade no sistema.

## DEFINIÇÃO
Observabilidade serve para:
- perceber padrões
- expor tendências
- manter consciência sistêmica

Observabilidade **NÃO serve** para:
- acionar decisões
- corrigir comportamentos
- otimizar resultados
- justificar controle

## REGRA DE NÃO-AÇÃO
Nenhum sinal observado pode:
- disparar fluxo
- alterar UX automaticamente
- gerar CTA
- justificar bloqueio ou limitação

Observabilidade termina sempre em **exposição neutra**.
