# Cursor Guardrails — UnifiCard

Este documento define **regras obrigatórias** para qualquer atuação do Cursor no projeto UnifiCard.

## REGRAS ABSOLUTAS
- NÃO criar lógica de decisão automática
- NÃO criar ranking, score social ou priorização oculta
- NÃO introduzir automação corretiva
- NÃO alterar comportamento humano
- NÃO modificar o CORE sem emenda explícita
- NÃO inferir intenção humana

## PRINCÍPIO
O Cursor **materializa contratos**, não resolve problemas humanos.

Se algo parecer uma "boa ideia" mas não estiver autorizado por contrato explícito, **não faça**.

Violação destas regras invalida o código, mesmo que funcione.
