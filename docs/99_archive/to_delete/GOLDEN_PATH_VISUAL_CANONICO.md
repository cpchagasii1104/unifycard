## GOLDEN PATH VISUAL POR MÓDULO

### MARKETPLACE

#### Ponto de Entrada Visual
O usuário entra vendo uma **Home / Discovery Page** com múltiplos blocos:
- Vitrine de produtos em destaque
- Categorias navegáveis
- Lojas populares
- Ofertas e promoções

**Percepção:** "Estou em um mercado onde posso explorar produtos e lojas."

#### Primeira Ação que o Usuário Entende
O usuário entende que pode:
- **Clicar em um produto** para ver detalhes
- **Clicar em uma categoria** para explorar
- **Clicar em uma loja** para ver o catálogo completo

**Percepção:** "Posso explorar livremente sem pressão para comprar."

#### Caminho Principal Percebido
1. **Exploração** → Usuário navega por produtos, categorias ou lojas
2. **Visualização** → Usuário vê detalhes de produto ou loja (Entity Detail Page)
3. **Adição ao Carrinho** → Usuário adiciona produtos (visual, não ação final)
4. **Checkout** → Usuário navega para página dedicada de checkout (Action Page)

**Percepção:** "Vejo opções, escolho o que quero ver, adiciono ao carrinho, e só então decido comprar."

#### Onde Acontecem Decisões Explícitas
- **Página de Checkout** (Action / Checkout Page)
  - Resumo completo do pedido
  - Método de pagamento explícito
  - Confirmação obrigatória
  - Impacto financeiro visível

**Percepção:** "Aqui é onde eu confirmo minha compra de forma consciente."

#### Onde o Usuário "Sabe o Que Fazer"
- **Home / Discovery:** "Posso explorar e navegar"
- **Entity Listing:** "Posso comparar e escolher"
- **Entity Detail:** "Posso ver detalhes e adicionar ao carrinho"
- **Action / Checkout:** "Preciso confirmar minha compra aqui"

**Percepção:** Cada página tem propósito visual claro, sem ambiguidade.

## PRINCÍPIOS VISUAIS DO GOLDEN PATH

### Clareza de Propósito
Cada página no Golden Path deve ter propósito visual claro. O usuário deve entender imediatamente:
- Onde está
- O que pode fazer
- Para onde pode ir

### Progressão Natural
O caminho visual deve fluir naturalmente:
- Exploração → Visualização → Declaração → Confirmação
- Sem saltos abruptos
- Sem ambiguidade sobre próximos passos

### Decisões Sempre Explícitas
Todas as decisões importantes aparecem em páginas dedicadas (Action / Checkout Page):
- Confirmação obrigatória
- Impacto visível
- Opção clara de cancelar

### Sem Pressão Visual
Nenhuma página do Golden Path deve:
- Forçar ação imediata
- Bloquear navegação
- Ocultar informações necessárias
- Criar urgência artificial
