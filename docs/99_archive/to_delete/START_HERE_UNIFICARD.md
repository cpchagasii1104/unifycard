## Guia Rápido de Leitura e Onboarding Institucional

Este documento é a porta de entrada prática para qualquer pessoa
(humana ou IA) que precise entender, operar ou evoluir o UnifiCard.

VINCULANTE.

---

## COMO USAR (5 MINUTOS)

1. Leia este arquivo inteiro.
2. Vá para o Índice Institucional.
3. Siga apenas os caminhos indicados.
4. Nunca pule documentos canônicos.

---

## O QUE O UNIFICARD É (E NÃO É)

É:
- sistema institucional
- economia controlada
- execução explícita
- reversibilidade como CORE

Não é:
- app improvisado
- checkout disfarçado
- automação decisória
- UX que promete o que não aconteceu

## SE VOCÊ É IA

Regras:
- não decida
- não interprete
- não improvise
- execute somente após autorização explícita

Documento manda.

---

## ERROS COMUNS (EVITE)

- mudar domínio no código
- ativar economia por flag
- misturar autorização com execução
- criar UX ambígua
- pular checklist

Todos são bloqueáveis — use os documentos.

## ENCERRAMENTO

Se houver confusão:
- o erro não é técnico
- é leitura incompleta

Este guia existe para evitar isso.
