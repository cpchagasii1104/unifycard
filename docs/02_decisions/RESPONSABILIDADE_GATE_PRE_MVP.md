# RESPONSABILIDADE GATE PRÉ-MVP

## Status
APROVADO • CANÔNICO • VINCULANTE

## Contexto

Este documento define a responsabilidade institucional para o cumprimento dos gates pré-MVP antes da abertura de MVP público.

---

## DECISÃO INSTITUCIONAL

**Abrir MVP público sem cumprir todos os gates pré-MVP é uma violação institucional.**

Esta violação:
- Compromete a integridade arquitetural do sistema
- Viola contratos canônicos estabelecidos
- Põe em risco a consistência e confiabilidade do UnifiCard

---

## RESPONSABILIDADE

A decisão de abrir MVP público:
- **DEVE** ser explícita
- **DEVE** ser registrada
- **DEVE** referenciar o checklist de enforcement
- **DEVE** confirmar que todos os gates foram validados

---

## PROCESSO OBRIGATÓRIO

Antes de qualquer abertura de MVP público:

1. Executar `CHECKLIST_ENFORCEMENT_PRE_MVP.md`
2. Validar que todos os gates = PASS
3. Registrar decisão explícita
4. Documentar evidências de cumprimento

**Sem cumprimento deste processo → abertura de MVP público é inválida.**

---

## VIOLAÇÃO INSTITUCIONAL

Abrir MVP público sem:
- Cumprir todos os gates pré-MVP
- Executar checklist de enforcement
- Registrar decisão explícita
- Documentar evidências

É considerado **violação institucional** e invalida a abertura do MVP público.
