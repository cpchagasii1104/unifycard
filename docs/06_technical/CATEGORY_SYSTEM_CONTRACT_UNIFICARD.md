# CATEGORY SYSTEM CONTRACT — UNIFICARD
Status: CANONICAL · BINDING
Scope: Taxonomy · Classification · Read Models

Categories in UnifiCard are **descriptive only**.
They exist to help humans navigate information.

## Absolute Rules
- Categories NEVER decide behavior
- Categories NEVER gate access
- Categories NEVER affect pricing, ranking or visibility
- Categories NEVER imply competence, merit or trust

Categories are **read-model metadata**, not policy.

## Prohibitions
- if(category == X)
- category-based permissions
- category-based scoring

Violation of this contract is **anticore**.
