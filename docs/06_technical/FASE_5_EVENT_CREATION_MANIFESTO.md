
# FASE 5.0 — EVENT CREATION ORCHESTRATION
## Manifesto Canônico

Este documento define regras semânticas, operacionais e institucionais da Fase 5.0.

## Princípio Central
Nenhuma etapa desta fase cria existência econômica, jurídica ou contratual.

## O que ESTA fase faz
- Declara intenções
- Mapeia possibilidades
- Simula cenários (TEST)
- Consolida entendimento

## O que ESTA fase NÃO faz
- Não paga
- Não contrata
- Não reserva
- Não confirma
- Não cria obrigações

## Regras Semânticas Obrigatórias
- Evento = Rascunho
- Data = Janela possível
- Local = Requisito de espaço
- Fornecedor = Papel operacional
- Valor = Intervalo estimado (TEST)

## Kill Switch Institucional
Qualquer tentativa de:
- Confirmar data
- Fixar valor
- Escolher fornecedor real
- Executar split
DEVE ser bloqueada.

## Encerramento
Este documento é obrigatório para backend, frontend e produto.
