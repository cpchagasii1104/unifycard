# Contratos de Observabilidade — Resumo Oficial

Este arquivo resume os contratos O-01 a O-06 para uso do Cursor.

## O-01 — Densidade Cognitiva
Observa carga decisória agregada.
Nunca indivíduos.

## O-02 — Normalização
Observa perda de variação comportamental.
Nunca eficiência.

## O-03 — Concentração Humana
Observa centralidade emergente.
Nunca nomeia pessoas.

## O-04 — Visibilidade
Observa distribuição de atenção.
Nunca rebalanceia feed.

## O-05 — Quebra de Padrão
Permite variação semântica neutra.
Nunca induz escolha.

## O-06 — Memória Temporal
Observa tendências longas.
Nunca moraliza passado.

Qualquer uso fora disso é violação constitucional.
