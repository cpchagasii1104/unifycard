## PILOTO 1: REDE TECH (Mês 2 - Fevereiro 2026)

### Objetivo

**Validação técnica** do sistema com usuários que:
- Entendem que é piloto (não produto final)
- Dão feedback qualificado
- Toleram bugs não-críticos
- Ajudam a encontrar edge cases

**NÃO é:**
- ❌ Lançamento público
- ❌ Produto acabado
- ❌ Marketing
- ❌ Captação de investimento

**Quem entra:**

```

✅ Profissionais de TI

```

#### 7. MFI Coins Conversíveis ✅

**O que funciona:**
```
✅ Receber MFI por serviços/produtos

✅ Converter MFI ↔ BRL

```


**Exemplo:**
```
Usuário deposita R$ 100,00 via PIX
→ Recebe 100 MFI (taxa 0%)

Usuário converte 100 MFI para BRL
→ Recebe R$ 98,00 (taxa 2% = R$ 2,00)
```
