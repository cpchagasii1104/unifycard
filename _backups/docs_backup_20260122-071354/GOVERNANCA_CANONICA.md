# UNIFICARD — GOVERNANÇA CANÔNICA (v1)

Este documento é **fonte de verdade institucional** do sistema UnifiCard.
Ele existe para alinhar código, decisões econômicas e expectativas humanas.

Nada neste repositório deve violar este contrato.

---

## 1. NATUREZA DO SISTEMA

UnifiCard **não é um app**, não é um marketplace tradicional e não é um banco.

É um **sistema institucional com núcleo econômico próprio**, operado inicialmente com moeda fictícia (MFI),
desenhado para coordenação social, prestação de serviços e organização comunitária.

---

## 2. PRINCÍPIOS INEGOCIÁVEIS

### 2.1 Soberania Econômica
- Todo fluxo econômico passa pelo **Unify Bank**
- Não existe saldo fora do Bank
- Não existe cálculo financeiro fora do Bank

### 2.2 Verdade Contábil
- Ledger é imutável (append-only)
- Saldos são sempre derivados do ledger
- Reversões restauram o estado exatamente

### 2.3 Transparência Sistêmica
- Toda taxa é explícita
- Todo split é auditável
- Toda transação é rastreável

---

## 3. POLÍTICA ECONÔMICA (PILOTO)

### 3.1 Moeda
- Unidade: **MFI (moeda fictícia interna)**
